# The World in One Day — 17 November 2026

A single picture of one day's world news, entered in make.fun's
news-image-20261117 competition.

The broadsheet holds 32 stories from Tuesday 17 November 2026.
Across the top runs a banner photograph of a sea bridge with a
collapsed span beneath a burning sky. The two lead items are Ukraine
striking the Kerch Bridge again, and a fourth tanker hit in the
Strait of Hormuz as the US-Iran war escalates. Fifteen more stories
cover the rest of the world and fifteen cover Indonesia, set in three
dense columns of real type so each headline can still be read.

Running `main.py` (Python 3.13, standard library only) places the
bundled `frontpage.jpg` — 1024 by 1024 pixels, under one mebibyte —
at `/output/entry.png`, byte for byte, every time.
